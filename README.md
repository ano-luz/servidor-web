Servidor Web

Esse projeto visa criar um servidor web para Linux usando a linguagem C.

A intenção é fazer o máximo possível "na mão", sem usar bibliotecas de terceiros, para entender o máximo possível do que está sendo feito.

O objetivo é manter o código o mais simples e claro possível, por isso deve-se usar a sintaxe básica da linguagem C evitando coisas mais complicadas e confusas.

O principal de um servidor web é implementar o protocolo TLS 1.3 que garante segurança na troca de dados entre o navegador do usuário e o servidor do site.

Então o principal desafio é implementar algoritmos de criptografia usados no TLS 1.3.

O arquivo "status.md" contem a situação atual do desenvolvimento do servidor web, indicando qual o próximo desafio a ser superado.

O arquivo "finalizado.md" contém os desafios já superados.

O arquivo "visao-geral.md" contém uma descrição do passo a passo no desenvolvimento do servidor web.
